OpenAI and Atlassian expand partnership to embed GPT‑6 models into enterprise tools

OpenAI and Atlassian have extended their collaboration so that GPT‑6 frontier models power AI agents across Atlassian’s platform, including Jira and Confluence. The partnership gives Atlassian customers access to models such as GPT‑6 Astra and GPT‑5.6, and uses Atlassian’s Teamwork Graph to give AI a deep understanding of a company’s work. The goal is to make AI agents a natural part of everyday work in tools teams already use.

Why it matters: Teams can get AI help directly inside the software they use for planning and building, which can speed up work and reduce manual effort.

Falcon-Emirati model specializes in Emirati Arabic

The Technology Innovation Institute (TII) released Falcon-Emirati-7B, a language model tuned to understand and generate Emirati Arabic, a Gulf dialect. It builds on the Falcon-H1-Arabic base and focuses on dialect vocabulary, tone, and cultural context. The model aims to improve communication for native speakers and developers working with Emirati Arabic content.

Microsoft and Hugging Face release ThinkingBox benchmark to test AI agent consistency

Microsoft and Hugging Face introduced ThinkingBox, a benchmark that runs AI agents through 507 business workflows many times, checking the actual changes an agent makes to a database rather than just the tool calls it reports. The study found that a majority of agents leave incorrect or incomplete backend states even when they appear to have succeeded. This shows that current testing methods miss hidden errors in agent behavior.
